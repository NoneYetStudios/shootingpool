# World Firearm Billiards Championship

Pool, except you choose a firearm instead of a cue stick.

Play online:
https://shootingpool.stabthefinger.com/

## About

World Firearm Billiards Championship is a browser-based billiards game that explores the consequences of making poor sporting-equipment choices.

Choose a firearm, line up your shot, and attempt to prove that cue sticks were never actually necessary.
